# Services / Послуги

**Client outcomes:** website requests into an operator queue; approvals with roles and status; API integrations with error and duplicate handling; small staff panels; focused Python bot fixes.

**Python backend, automation and integrations.** I agree on scope, acceptance checks and handover before starting. Price, delivery date and support terms follow task assessment.

## 1. Python bot or integration fix / Виправлення Python-бота чи інтеграції

**Scope / Межі:** one reproducible failure and its affected path.  
**Inputs / Потрібно:** expected behaviour, sanitized error or reproduction, access to the agreed code scope.  
**Deliverable / Результат:** a focused fix, an explanation of the cause and a relevant regression check.  
**Acceptance / Приймання:** the original reproduction and an agreed nearby failure case behave correctly.  
**Separate assessment / Окрема оцінка:** unrelated defects, a full rewrite, production rollout or continuing support.

## 2. API to application or SQL / Інтеграція API із застосунком чи SQL

**Scope / Межі:** one authorized data flow between documented systems.  
**Inputs / Потрібно:** API documentation, synthetic examples, data mapping and access requirements.  
**Deliverable / Результат:** integration logic, configuration notes and agreed failure handling.  
**Acceptance / Приймання:** valid, duplicate and timeout cases produce the agreed result.  
**Separate assessment / Окрема оцінка:** undocumented providers, large historical migrations, provider availability or high-load guarantees.

## 3. Telegram requests and approvals / Заявки та погодження в Telegram

**Scope / Межі:** a defined workflow for authorized users, with roles, status changes and notifications.  
**Inputs / Потрібно:** role list, workflow rules, sample requests and a controlled test environment.  
**Deliverable / Результат:** workflow implementation, data model within scope and handover notes.  
**Acceptance / Приймання:** role checks, repeated input and agreed restart behaviour are demonstrated.  
**Separate assessment / Окрема оцінка:** external service charges, complex migrations or continuous operations. Bulk outreach is outside this offer.

## 4. Internal dashboard / Внутрішня вебпанель

**Scope / Межі:** a small set of administrative screens and actions connected to an agreed backend.  
**Inputs / Потрібно:** operator tasks, roles, API or data contract and synthetic records.  
**Deliverable / Результат:** usable screens, backend integration and setup notes.  
**Acceptance / Приймання:** agreed actions, access rules, empty states and error states work on the controlled dataset.  
**Separate assessment / Окрема оцінка:** full product design, complex multi-tenant architecture, mobile apps or a public SaaS launch.

## 5. Automation state and recovery / Стани й відновлення автоматизації

**Scope / Межі:** one repeated-action, stalled-job or uncertain-outcome problem.  
**Inputs / Потрібно:** sanitized event timeline, expected state and a controlled reproduction.  
**Deliverable / Результат:** diagnosis, a scoped change and a check for the identified failure.  
**Acceptance / Приймання:** the agreed repeated-event, interrupted or timeout scenario reaches its defined state.  
**Separate assessment / Окрема оцінка:** load certification, zero-downtime guarantees or all failures in an undocumented external system.
