# Python-розробник | Backend, автоматизація та інтеграції API

## Коротке представлення

Створюю backend-інструменти на Python, інтеграції API та Telegram-процеси. Допоможу з обробкою заявок, внутрішніми панелями й конкретними помилками в автоматизації. У моїх проєктах є робота зі станами, SQL-транзакціями та відновленням після збоїв. Обсяг роботи й критерії перевірки погоджую до початку.

## Про мене

Я Антон Городничий, Python-розробник із фокусом на backend та автоматизацію. Перетворюю ручний процес на зрозумілий сценарій: отримати заявку, перевірити її, оновити стан і показати результат відповідальному працівнику.

Я спроєктував і реалізував процеси подання та перевірки заявок, інтеграції підтримки, адміністративні вебінтерфейси й локальні інструменти керування задачами. У портфоліо описано завдання, мій внесок, технічний підхід та обмеження. Вихідний код залишається приватним.

У наявній системі починаю з відтворюваного прикладу проблеми й конкретної зміни. Для нового інструмента спочатку погоджую ролі користувачів, межі даних і сценарії приймання. Готую інструкції запуску та передачі результату відповідно до обсягу роботи.

## Основний стек

Python, asyncio, FastAPI, SQLite, PostgreSQL, SQLAlchemy, aiogram, Telethon, HTTP API, Jinja2, HTML/CSS/JavaScript. У проєктах використано інструменти тестування pytest та unittest.

## Послуги

- Виправлення конкретної помилки в Python-боті або інтеграції.
- Підключення погодженого API до застосунку чи бази даних.
- Telegram-процеси для заявок, перевірок і підтримки.
- Невеликі внутрішні панелі та адміністративні інтерфейси.
- Діагностика повторної обробки подій, станів і таймаутів.

Зміну в погоджених межах, перевірки основного сценарію та відмов, зрозумілі інструкції й передачу результату. Ціна, строки та умови підтримки визначаються після оцінки завдання.
